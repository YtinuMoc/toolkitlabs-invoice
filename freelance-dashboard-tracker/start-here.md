## 10-minute setup

1. Copy `revenue-template.csv` and `expenses-template.csv`.
2. Log payments and expenses as they happen — not in a quarterly catch-up batch.
3. Run the dashboard:

```bash
python3 freelance_dashboard_tracker.py revenue-sample.csv expenses-sample.csv
```

4. Run the 15-minute weekly protocol from [spreadsheet-trap-guide.md](spreadsheet-trap-guide.md).
