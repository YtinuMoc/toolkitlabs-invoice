# Freelance Dashboard

Shameless clone of [Anna Hickman — Freelance Dashboard](https://cedabranding.gumroad.com/l/pro-dashboard) ($97 on Gumroad · **1,251 sales** · **69 ratings · 4.9★**).

Planning-layer dashboard for freelancers: revenue, expenses, client mix, tax set-aside, and cash runway — without a $140/mo accounting subscription.

## Quick start

```bash
python3 freelance_dashboard_tracker.py revenue-sample.csv expenses-sample.csv
```

Spreadsheet-trap buyer channel (wilsonhoe/4khk shape):

```bash
python3 freelance_dashboard_tracker.py --spreadsheet-trap revenue-sample.csv expenses-sample.csv
```

## Files

- `revenue-template.csv` / `revenue-sample.csv` — client payments
- `expenses-template.csv` / `expenses-sample.csv` — categorized spending
- `freelance_dashboard_tracker.py` — dashboard CLI
- `start-here.md` / `faq.md` / `spreadsheet-trap-guide.md`
