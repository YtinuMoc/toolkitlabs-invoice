# Start here — Pinterest SEO & Pin Performance Dashboard

1. Copy all `*-template.csv` files to your working names.
2. Export Pinterest Analytics weekly — paste impressions, pin clicks, outbound clicks, saves per pin.
3. Run `python3 pinterest_dashboard.py` with your CSV paths.
4. Review top performers by **outbound clicks** (not impressions).
5. Run A/B tests on headline/color/CTA — log results in `ab-test-*.csv`.
6. Monthly: update `monthly-analytics-*.csv` and compare to goal_clicks.

Target metrics (from ioneldigital/46ea buyer channel):
- Save rate > 1%
- Outbound click rate > 0.3%
- Pin click rate > 1%
