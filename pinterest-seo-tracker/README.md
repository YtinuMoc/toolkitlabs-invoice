# Pinterest SEO & Pin Performance Dashboard

Clone of [AnahitDigitalStudio batvmj ($8.99)](https://anahitstudio.gumroad.com/l/batvmj) on Gumroad.

CSV logs + Python CLI replacing the Notion workspace:

- Pin Performance Tracker — impressions, clicks, outbound clicks, saves, rates, performance rating
- Pinterest Board Planner — board topics, keywords, pin counts
- Pin A/B Test Tracker — compare two pin versions, auto-winner
- Monthly Pinterest Analytics — impressions, clicks, saves, goals
- Keyword Research — search volume, competition, board assignment

## Quick start

```bash
python3 pinterest_dashboard.py pin-performance-sample.csv board-planner-sample.csv ab-test-sample.csv monthly-analytics-sample.csv keyword-research-sample.csv
```

Copy `*-template.csv` files to start your own data.
