# Ultimate Finance Tracker

Shameless clone of [simonotion.gumroad.com/l/finance-tracker](https://simonotion.gumroad.com/l/finance-tracker) ($47 · 109 ratings · 5.0★).

## Files

| File | Purpose |
|------|---------|
| `income-template.csv` | Paychecks, side income, dividends |
| `expenses-template.csv` | Spending by category |
| `debts-template.csv` | Credit cards and loans |
| `savings-template.csv` | Goal targets and progress |
| `accounts-template.csv` | Bank and liability balances |
| `subscriptions-template.csv` | Recurring services |
| `investments-template.csv` | Stocks, crypto, real estate |
| `ultimate_finance_tracker.py` | Dashboard CLI |

## Quick start

```bash
python3 ultimate_finance_tracker.py income-sample.csv expenses-sample.csv debts-sample.csv savings-sample.csv accounts-sample.csv subscriptions-sample.csv investments-sample.csv
```
