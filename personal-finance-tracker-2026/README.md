# 2026 Personal Finance Tracker

Shameless clone of [ohmygoshna.gumroad.com/l/2026](https://ohmygoshna.gumroad.com/l/2026) ($13 · 7 ratings · 5.0★).

## Files

| File | Purpose |
|------|---------|
| `income-template.csv` | Paychecks, side income |
| `expenses-template.csv` | Daily spending by category |
| `debts-template.csv` | Credit cards and loans for snowball |
| `savings-template.csv` | Goal targets and progress |
| `accounts-template.csv` | Assets and liabilities for net worth |
| `personal_finance_tracker_2026.py` | Dashboard CLI |

## Quick start

```bash
python3 personal_finance_tracker_2026.py income-sample.csv expenses-sample.csv debts-sample.csv savings-sample.csv accounts-sample.csv
```
