# Freelance Finance OS

Shameless clone of [By the Loop's Freelance Finance OS ($5 on Gumroad)](https://bytheloop.gumroad.com/l/freelance-finance-os).

Four tools in one bundle:

1. **Invoice tracker** — draft/sent/paid/overdue status
2. **Expense + tax buffer** — category log + set-aside math
3. **Rate calculator** — offline HTML floor-rate tool
4. **Quarterly tax estimator** — 1040-ES deadline schedule

EUR 9 one-time via Stripe. Same delivery shape as the original xlsx bundle, shipped as CSV + CLI + HTML.
