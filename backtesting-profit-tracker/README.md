# Back-testing Profit Tracker

Shameless clone of [Ahead of the Trade — Back-testing Profit Tracker](https://aheadofthetrade.gumroad.com/l/ojdzA) ($1.99 · 35 Gumroad ratings).

Excel-based profit tracker for manual back-testing: prove strategy win rate before live trading.

## Quick start

```bash
python3 backtesting_profit_tracker.py trades-sample.csv
```

## Files

- `trades-template.csv` — blank log
- `trades-sample.csv` — 12 sample trades
- `backtesting_profit_tracker.py` — dashboard CLI
- `start-here.md` / `faq.md`
