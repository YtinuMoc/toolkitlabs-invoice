# Orion SMC Suite — Toolkit Labs clone

Shameless clone of [Orion's SMC Suite on Gumroad](https://nexusai82.gumroad.com/l/pine-smc) ($29 one-time). Five Pine Script v5 indicators for Smart Money Concepts trading on TradingView.

## Install

1. Open TradingView → Pine Editor
2. Paste each `.pine` file → **Add to chart**
3. Configure inputs per indicator

## Files

| File | What it does |
|------|--------------|
| `smc_fvg_lite.pine` | Fair Value Gap detector — free-tier shape from Orion dev.to |
| `smc_fvg_pro.pine` | FVG Pro — HTF overlay, ATR gap filter, strength class, alerts |
| `smc_liquidity_zones.pine` | BSL/SSL equal highs/lows + sweep events |
| `smc_order_blocks_mtf.pine` | Bull/bear order blocks + HTF overlay + strength score |
| `smc_session_levels.pine` | Asia/London/NY session high-low liquidity levels |
