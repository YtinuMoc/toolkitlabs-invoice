# Finance OS

Shameless clone of [heyismail — Finance OS Pro](https://heyismail.gumroad.com/l/TheUltimateFinanceTracker) ($29+ on Gumroad · 15,254 sales · 177 ratings · 4.9★).

All-in-one financial command center: income, expenses, budgets, subscriptions, net worth, and goals — updated the moment you log a transaction.

## Quick start

```bash
python3 finance_os_tracker.py income-sample.csv expenses-sample.csv budgets-sample.csv subscriptions-sample.csv accounts-sample.csv goals-sample.csv
```

## Files

- `income-template.csv` / `income-sample.csv` — log income by source and category
- `expenses-template.csv` / `expenses-sample.csv` — categorized spending
- `budgets-template.csv` / `budgets-sample.csv` — monthly limits by category
- `subscriptions-template.csv` / `subscriptions-sample.csv` — recurring charges + renewal dates
- `accounts-template.csv` / `accounts-sample.csv` — assets and liabilities for net worth
- `goals-template.csv` / `goals-sample.csv` — financial goal progress
- `finance_os_tracker.py` — command center CLI
- `start-here.md` / `faq.md` / `finance-os-guide.md`
