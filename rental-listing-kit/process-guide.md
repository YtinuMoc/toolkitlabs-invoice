# 30-minute vacancy listing process

| Step | Time | Action |
|------|------|--------|
| 1 | 3 min | Fill `property-brief-template.md` |
| 2 | 7 min | Run all-in-one prompt from `listing-prompts-free.md` — verify facts |
| 3 | 10 min | Shoot + order photos per `photo-checklist.md` |
| 4 | 10 min | Post Zillow → Apartments.com → Facebook → Craigslist |

## Platform posting order
1. **Zillow** — highest intent; 300-word description + full amenity list
2. **Apartments.com** — 150-word version
3. **Facebook Marketplace** — casual 120-word post
4. **Craigslist** — plain text ~100 words

## Common mistakes (quick fixes)
- **Generic title** — lead with neighborhood + price + top perk
- **Buried pet policy** — first 50 words if pet-friendly
- **No CTA** — end with "Contact [email] to schedule a showing"
- **Wrong photo order** — best room first, not the hallway
