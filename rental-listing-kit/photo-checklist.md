# Photo checklist — rental listings
Clone of Orion cojdwi / dev.to 4219900 Step 3.

## Before you shoot
- Landscape orientation (horizontal)
- Turn on every light — fills shadows, rooms look ~20% larger
- First photo = search thumbnail — make it your best wide living-room or kitchen shot

## Must-have shots (minimum 10 for 2BR)
- [ ] Living room — wide shot from each corner
- [ ] Kitchen — counters + appliances visible
- [ ] Each bedroom — from doorway, window + closet visible
- [ ] Bathroom — from doorway, lid down
- [ ] In-unit laundry — one photo (selling point)
- [ ] Parking — one photo if included
- [ ] Outdoor / building exterior if applicable

## Upload order
1. Best living room or kitchen (thumbnail)
2. Remaining living spaces
3. Bedrooms
4. Bath + laundry
5. Parking + exterior

Zillow allows 24 photos — use them if you have good shots.
