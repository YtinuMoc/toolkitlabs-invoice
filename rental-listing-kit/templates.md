# Platform listing templates
Fill brackets from your property brief. Same facts, different length/tone.

## Zillow title (max 80 chars)
```
[Neighborhood] [BR]BR $[RENT]/mo | [Top perk] | [Second perk]
```
Example: `South End 2BR $1,650/mo | In-Unit W/D | Parking Incl`

## Zillow description (~300 words)
```
[Neighborhood] [BR]/[BA] — $[RENT]/mo, available [DATE]

[Paragraph 1: location + commute/transit + who it's for]

[Paragraph 2: layout, sq ft, standout rooms]

Amenities:
• [Bullet 1 — in-unit laundry if applicable]
• [Bullet 2 — parking]
• [Bullet 3 — pets if applicable]
• [Bullets 4–10]

[CTA: Contact [EMAIL] to schedule a showing — available [DATE].]
```

## Apartments.com (~150 words)
```
[BR]/[BA], [SQ FT] sq ft in [Neighborhood]. $[RENT]/mo, available [DATE].
[Parking]. [Pet policy in first sentence if friendly].
[2 sentences on layout + top amenities].
Contact [EMAIL] for showings.
```

## Facebook Marketplace (~120 words)
```
🏠 [BR]/[BA] in [Neighborhood] — $[RENT]/mo

Available [DATE]. [One-line hook: parking / pets / transit].
[2–3 sentences, conversational tone].
Message or email [CONTACT] to tour this week.
```

## Craigslist (~100 words, plain text)
```
[BR]/[BA] [Neighborhood] $[RENT]/mo avail [DATE]
[Parking]. [Pets].
[Short layout description].
[Email] — mention this listing when you reply.
```
