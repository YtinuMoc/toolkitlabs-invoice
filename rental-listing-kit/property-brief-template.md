# Property brief template
Fill this out before writing copy. Same facts on every platform.

```
Property: [BR/BA], [SQ FT] sq ft
Location: [Neighborhood, City, State]
Rent: $[AMOUNT]/mo
Available: [Date]
Amenities: [In-unit W/D, dishwasher, hardwood, central AC, etc.]
Parking: [Spaces included / street / none]
Pets: [Policy — e.g. dogs up to 40 lbs]
Nearby: [Transit, parks, grocery — with realistic walk times]
Contact: [Email or phone for showings]
```

Reuse this brief for every vacancy. Paste into the all-in-one prompt in `listing-prompts-free.md`.
