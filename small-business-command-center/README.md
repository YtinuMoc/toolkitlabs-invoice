# Small Business Command Center

Shameless clone of [AnahitDigitalStudio tnjpdy ($12.99)](https://anahitstudio.gumroad.com/l/tnjpdy) on Gumroad.

22-in-1 promise as CSV logs + Python CLI: clients, sales, expenses, invoices, inventory, marketing, launches, P&L dashboard.

## Quick start

```bash
python3 business_dashboard.py sales-log-sample.csv expense-log-sample.csv invoice-tracker-sample.csv client-registry-sample.csv inventory-log-sample.csv marketing-campaign-sample.csv launch-planner-sample.csv
```

Copy `*-template.csv` files to start your own logs.
