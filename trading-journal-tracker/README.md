# Trading Journal Tracker

Shameless clone of [Jordi Square — Ultimate Trading Journal Spreadsheet](https://jordisquare.gumroad.com/l/tradingjournal) ($48 · 6 sales · creator 4.9/35 reviews).

Google Sheets journal for forex, crypto, futures, and stocks: log trades, calendar view, monthly/quarterly summaries, and reflection notes.

## Quick start

```bash
python3 trading_journal_tracker.py trades-sample.csv
```

## Files

- `trades-template.csv` — blank journal log
- `trades-sample.csv` — 15 sample trades across EURUSD, XAUUSD, BTCUSDT, GBPUSD
- `trading_journal_tracker.py` — dashboard CLI (calendar, monthly, by-market, reflections)
- `start-here.md` / `faq.md`
