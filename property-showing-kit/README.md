# AI Property Showing Kit (Orion trsoxh clone)

Shameless clone of [Orion's AI Property Showing Kit ($39)](https://nexusai82.gumroad.com/l/trsoxh).

## Files

- `pre-screening-questionnaire.md` — filter leads before they walk through the door
- `showing-scheduler.md` — confirmations, reminders, no-show follow-ups, batch scripts
- `showing-day-checklist.md` — 15-minute showing flow + unit prep
- `follow-up-templates.md` — 4 post-showing email templates + AI personalization prompts
- `pre-screening-free.md` — 5 free pre-screen questions (dev.to lead magnet)

## Quick start

1. Paste `pre-screening-free.md` questions into your inquiry reply (or use full questionnaire).
2. Schedule with templates from `showing-scheduler.md`.
3. Run `showing-day-checklist.md` on showing day.
4. Send follow-up from `follow-up-templates.md` within 2 hours.

Works with ChatGPT, Claude, or any LLM for the AI prompt blocks.
