# Showing Day Checklist

Clone of Orion trsoxh module 3 — 15-minute showing flow.

## 30 minutes before

- [ ] All lights on, blinds open, AC/heat comfortable
- [ ] Trash out, dishes away, beds made (if furnished/staged)
- [ ] Toilet lids down, towels neat
- [ ] Application link / QR printed on counter
- [ ] Lockbox tested; backup key on you
- [ ] Phone charged; prospect contact saved

## Unit prep checklist

- [ ] Entry / exterior: clean doorstep, working porch light
- [ ] Living areas: clear floors, minimal personal items
- [ ] Kitchen: counters clear, fridge closed, no odors
- [ ] Bedrooms: doors open, closets accessible
- [ ] Bathroom: clean, stocked paper
- [ ] Laundry: visible if selling point
- [ ] Parking spot shown if included

## 15-minute showing flow

| Minute | Action |
|--------|--------|
| 0–2 | Greet, verify ID, state fair-housing rules (same info to all) |
| 2–4 | Quick orientation: rent, deposit, pets, parking, move-in date |
| 4–12 | Self-guided tour — you stay available, don't hover |
| 12–14 | Answer questions; hand application link |
| 14–15 | Confirm follow-up channel; thank them |

## After every showing — notes to capture

- Names, contact, move-in date needed
- Income/pets discussed (already pre-screened?)
- Objections heard (price, location, condition)
- Interest level 1–5
- Competing properties they mentioned
- Follow-up template to use (apply / nurture / not a fit)

## AI prompt — debrief notes

```plaintext
Showing notes: [PASTE BULLETS]
Write a 3-bullet internal summary and recommend which follow-up template (apply now / nurture / not a fit / competing offer).
```
