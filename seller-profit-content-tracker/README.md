# Seller Profit & Content Tracker

Shameless clone of [AnahitDigitalStudio nxqiai](https://anahitstudio.gumroad.com/l/nxqiai) ($14.99 Gumroad).

12-tab spreadsheet promise → CSV logs + Python CLI. Tracks sales, platform fees, expenses, profit, Pinterest content, UTM campaigns, and product launches.

## Quick start

```bash
python3 seller_dashboard.py product-catalog-template.csv sales-sample.csv expense-sample.csv content-sample.csv utm-sample.csv launch-sample.csv
```

## Files

| File | Tab clone |
|------|-----------|
| `product-catalog-template.csv` | Product Catalog & Inventory |
| `sales-log-template.csv` | Sales Tracker + fee calculator |
| `expense-log-template.csv` | Income & Expense Tracker |
| `content-planner-template.csv` | Pinterest & Social Content Planner |
| `utm-campaigns-template.csv` | UTM Campaign Link Tracker |
| `launch-planner-template.csv` | Product Launch Planner |

## Platform fees (editable in `fee-settings.md`)

- Gumroad: 10% + $0.30
- Etsy: listing + transaction + processing + offsite ads
- Shopify: 2.9% + $0.30
