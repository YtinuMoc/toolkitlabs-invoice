# Fee settings

Default platform fee assumptions (AnahitDigitalStudio nxqiai clone):

| Platform | Assumption |
|----------|------------|
| Gumroad | 10% + $0.30 per sale |
| Etsy | $0.20 listing + 6.5% transaction + 3% + $0.25 processing |
| Shopify | 2.9% + $0.30 |
| Other | 0% (enter fees manually in sales log if needed) |

Edit `PLATFORM_FEES` in `seller_dashboard.py` if your rates differ.

This is an organizational tool — not tax or accounting advice.
