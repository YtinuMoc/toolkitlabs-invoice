# STR Host AI Toolkit
Shameless clone of [Orion's STR Host AI Toolkit on Gumroad](https://nexusai82.gumroad.com/l/muieqx) ($27 one-time).

## What's inside
- **60 AI prompts** — complaint handling, listing copy, pricing, reviews, ops, marketing (`prompts.md`)
- **12 message templates** — inquiry through checkout (`templates.md`)
- **45-point listing audit** — score before you spend on ads (`listing-audit.md`)
- **Revenue tracker CSV** — monthly RevPAR/ADR sanity checks (`revenue-tracker.csv`)
- **7 free complaint prompts** — same as Orion's dev.to buyer channel (`complaint-prompts-free.md`)

## Quick start
1. Open `complaint-prompts-free.md` — paste prompt #1 into your LLM tonight when the next guest message arrives.
2. Run `listing-audit.md` on your weakest listing — fix anything scoring under 2 on items 1–20.
3. Copy `templates.md` #1–#4 into your PMS canned responses.

Pair with [SellerLedger CLI](../ledger/) to merge platform CSVs into P&L after bookings land.
