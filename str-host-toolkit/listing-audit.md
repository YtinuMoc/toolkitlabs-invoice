# 45-point STR listing audit
Clone of Orion muieqx. Score each 0 (missing) / 1 (weak) / 2 (strong). Target 70+ / 90 before paid ads.

## Hero & photos (1–10)

1. Cover photo shows best room in daylight
2. 20+ photos, logical room order
3. Every bed shown with made bedding
4. Bathroom clean + amenities visible
5. Kitchen stocked photo if claimed
6. Exterior / building entrance clear
7. No wide-angle distortion on small rooms
8. Captions or alt text on key photos
9. Seasonal photos updated within 12 months
10. No watermarks or stock photo mismatch

## Title & description (11–20)

11. Title states beds + standout hook under 50 chars
12. First paragraph answers "why here" in 3 sentences
13. No vague filler (spacious, nice, beautiful)
14. WiFi speed number if targeting remote workers
15. Parking instructions explicit
16. Check-in/out times in description
17. Neighborhood walkability with named places
18. Honest downside disclosed (stairs, noise, etc.)
19. House rules linked or inlined
20. Same facts across Airbnb/Vrbo/direct

## Pricing & calendar (21–28)

21. Cleaning fee covers actual cost + margin
22. Weekend/seasonal pricing rules set
23. Minimum nights aligned with turnover cost
24. Gap nights strategy (discount or block)
25. Extra guest fee matches capacity
26. Security deposit / damage policy clear
27. Calendar synced across platforms
28. Blocked dates for owner use documented

## Guest journey (29–36)

29. Automated pre-arrival message tested
30. Door code / lock instructions accurate
31. Mid-stay check-in message scheduled
32. Checkout instructions sent night before
33. Complaint response playbook saved (see prompts.md)
34. Review response templates ready
35. Local guide (PDF or message) with emergencies
36. Backup contact if host unreachable

## Operations (37–42)

37. Turnover checklist per property
38. Cleaner notification on new booking
39. Restock list with par levels
40. Maintenance vendor on retainer or list
41. Smart lock battery / key backup plan
42. Linen + consumable storage organized

## Trust & compliance (43–45)

43. Refund / cancellation policy matches platform
44. License / registration number displayed if required
45. Insurance policy active + docs accessible
