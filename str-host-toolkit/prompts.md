# 60 STR host AI prompts
Clone of Orion's [STR Host AI Toolkit](https://nexusai82.gumroad.com/l/muieqx) ($27). Organized by guest journey stage. Paste into any LLM.

## Complaint handling (1–12)

1. **De-escalation first responder** — see complaint-prompts-free.md #1
2. **Root-cause triage** — see complaint-prompts-free.md #2
3. **Here's the fix reply** — see complaint-prompts-free.md #3
4. **Fair-compensation calculator** — see complaint-prompts-free.md #4
5. **Boundary reply** — see complaint-prompts-free.md #5
6. **Post-resolution follow-up** — see complaint-prompts-free.md #6
7. **Public review response** — see complaint-prompts-free.md #7
8. **Safety escalation** — "Guest reports [SAFETY ISSUE]. Draft a reply that takes it seriously, states immediate action (maintenance dispatch / alternate accommodation if needed), and asks for photos. Under 120 words. No liability admissions."
9. **Noise complaint neighbor** — "Guest complains about noise from [SOURCE]. House rules say [PASTE]. Write reply acknowledging impact, restating quiet hours, and offering earplugs/white-noise app tip. Under 90 words."
10. **Cleaning miss** — "Guest says [AREA] wasn't clean on check-in. Write apology, offer same-day re-clean or partial credit options, ask for photos. Under 100 words."
11. **Amenity outage** — "[AMENITY] broken during stay. Write reply with workaround, ETA for fix, and goodwill if fix takes >24h. Under 100 words."
12. **Platform case prep** — "Summarize this thread for an Airbnb support case: [PASTE MESSAGES]. Bullet: facts, my offers, guest asks, evidence I have. Neutral tone."

## Listing copy (13–24)

13. **Headline variants** — "Property: [BEDS/BATH/LOCATION/HOOK]. Write 5 listing headlines under 50 chars each. Lead with the strongest differentiator."
14. **First-paragraph hook** — "Listing details: [PASTE]. Write opening paragraph that answers 'why stay here' in 3 sentences. No filler ('spacious', 'nice')."
15. **Room-by-room walkthrough** — "Photos cover: [LIST ROOMS]. Write 2-sentence description per room highlighting what guests care about (bed size, desk, view)."
16. **Neighborhood guide** — "Address area: [CITY/NEIGHBORHOOD]. List 5 walkable highlights (coffee, grocery, transit) with realistic walking times."
17. **House rules tone** — "My rules: [PASTE DRAFT]. Rewrite firm rules (no parties, quiet hours) in friendly host voice without weakening them."
18. **Pet policy block** — "Pet policy: [DETAILS]. Write clear pet section: what's allowed, fees, cleanup expectations. 80 words max."
19. **Work-from-home angle** — "Listing has [DESK/WIFI SPEED]. Write a 'remote work ready' bullet block for digital nomads. Specific numbers only."
20. **Family-friendly block** — "Amenities for families: [CRIB/HIGH CHAIR/TOYS]. Write family section without overpromising safety certifications."
21. **Seasonal hook** — "Property near [SKI/BEACH/EVENT]. Write seasonal paragraph for [MONTH] travelers. One concrete activity per sentence."
22. **Competitive diff** — "My listing vs comps: [PASTE 2 COMP URLs OR BULLETS]. What should I emphasize that they don't? 5 bullets."
23. **Photo caption set** — "For each photo filename [LIST], write 1-line caption for Zillow/Airbnb upload order (exterior → living → beds → bath)."
24. **Multi-platform adapt** — "Core listing: [PASTE]. Adapt to [ZILLOW/FB/CRAIGSLIST] tone and length limits. Keep facts identical."

## Pricing & revenue (25–34)

25. **Weekend premium check** — "Last 90 days occupancy: [DATA]. Should I raise weekend rate by X%? Give low/mid/high recommendation with one-line rationale."
26. **Gap-night filler** — "I have [DATES] empty between bookings. Suggest discount % or minimum-night rule change to fill without training bargain hunters."
27. **Length-of-stay discount** — "Nightly rate $[X]. Propose weekly/monthly discount tiers that protect margin. Show math."
28. **Event surge** — "Event: [NAME] on [DATE] near my property. Suggest surge multiplier vs baseline with comp sanity check."
29. **Fee transparency** — "My all-in guest price is [X] after platform fees. Write one sentence for listing that sets fee expectations without sounding defensive."
30. **Break-even nights** — "Fixed costs $[MORTGAGE/HOA/UTILITIES] monthly. At $[ADR] and [OCCUPANCY]%, how many nights to break even? Table format."
31. **RevPAR post-mortem** — "Month: [PASTE BOOKINGS CSV SUMMARY]. Calculate RevPAR, ADR, occupancy. One paragraph what to change next month."
32. **Cleaning fee audit** — "Cleaning costs $[ACTUAL]. I charge $[FEE]. Is fee aligned? Suggest adjustment if margin <15%."
33. **Shoulder season plan** — "Slow months: [LIST]. 3 tactics (pricing, min nights, amenities) ranked by effort vs impact."
34. **Comp set scrape** — "Comps: [PASTE 3 LISTING SNIPPETS]. Where am I over/under priced? Bullet per comp."

## Reviews & reputation (35–42)

35. **Review request (in-stay)** — "Guest checked in yesterday, everything smooth. Write check-in message that opens door for feedback without begging for 5 stars. Under 60 words."
36. **Checkout thank-you** — "Guest checking out today. Warm thank-you message mentioning one specific thing about their stay [DETAIL]. No review ask. Under 70 words."
37. **4-star salvage** — "Guest left 4 stars citing [ISSUE]. Public response for future guests: acknowledge, state fix, invite back. Under 100 words."
38. **Unfair review response** — "Review claims [FALSE CLAIM]. Facts: [PASTE]. Public reply: calm, factual, for future readers. No arguing."
39. **Review theme analysis** — "Last 20 reviews: [PASTE]. Cluster themes (positive/negative). Top 3 operational fixes."
40. **Superhost gap** — "My metrics: [RESPONSE RATE/CANCEL RATE/RATING]. What's blocking Superhost? Prioritized checklist."
41. **Guest compliment reply** — "5-star review says [PASTE]. Write short public thank-you that reinforces one listing promise for future readers."
42. **Repeat guest nurture** — "Past guest [NAME] stayed [DATES]. Write rebooking offer message for same season next year. Personal, not spammy."

## Operations & turnover (43–52)

43. **Turnover checklist** — "Property: [BEDS/BATH]. Generate room-by-room turnover checklist for cleaner. Checkbox format."
44. **Cleaner brief** — "Issue from last guest: [PASTE]. Write cleaner instruction note for next turnover. Bullet facts only."
45. **Restock list** — "Standard consumables for [X]-bed STR. Quantities per turnover (toilet paper, soap, coffee). Table."
46. **Lock code rotation** — "Write guest message with new door code [CODE], check-in time, parking, WiFi. Under 120 words."
47. **Late checkout negotiation** — "Guest asks late checkout. Calendar shows [NEXT BOOKING]. Draft yes/no with boundary and fee if applicable."
48. **Maintenance vendor email** — "Issue: [PASTE]. Email to handyman: scope, access, photos attached, urgency. Professional, brief."
49. **Supply emergency** — "Cleaner reports missing [ITEM] before check-in in 4 hours. Options ranked: buy local, swap from unit B, message guest."
50. **Seasonal opening** — "Opening seasonal property after [MONTHS] vacant. 15-point reopen checklist (utilities, pests, linens, detectors)."
51. **Tax expense categorize** — "Receipt: [VENDOR/AMOUNT/DESCRIPTION]. STR Schedule E category? One line + note for accountant."
52. **Insurance claim prep** — "Incident: [DAMAGE]. Bullet facts for insurer: date, cause, photos, estimated cost, guest involvement."

## Marketing & inquiries (53–60)

53. **Inquiry first response** — "Guest asks: [PASTE]. Answer question, mirror dates/guest count, soft CTA to book. Under 100 words."
54. **Price objection** — "Guest says we're expensive vs [COMP]. Reply with value anchors (not discount first). Under 90 words."
55. **Long-term inquiry** — "Guest wants [30+ DAYS]. Outline policy, rate, utilities, screening steps. Professional tone."
56. **Local event pitch** — "Event [NAME] [DATES]. Write 2-sentence calendar note for listing description update."
57. **Photo reshoot brief** — "Weak photos: [LIST]. Shot list for photographer: angle, time of day, staging per room."
58. **Social post** — "Property hook: [UNIQUE FEATURE]. Write 3 Instagram captions (short/medium/long) with hashtags capped at 5."
59. **Email past guests** — "Subject + body for off-season 10% return guest offer. One CTA, unsubscribe line."
60. **Referral ask** — "Happy guest checking out. Message asking referral to friends (no incentive unless [OFFER]). Under 80 words."
