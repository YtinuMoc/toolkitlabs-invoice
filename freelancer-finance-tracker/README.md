# Freelancer Finance Tracker

Shameless clone of [Dirk Coetzee — Freelancer Finance Tracker](https://moonlight573.gumroad.com/l/unsjlk) ($10 on Gumroad).

Live dashboard promise: income, expenses, net profit, outstanding invoices, and tax set-aside — updated the moment you log a payment or expense.

## Quick start

```bash
python3 freelancer_finance_tracker.py income-sample.csv expenses-sample.csv invoices-sample.csv
```

## Files

- `income-template.csv` / `income-sample.csv` — log payments by client and project
- `expenses-template.csv` / `expenses-sample.csv` — categorized spending with deductible flags
- `invoices-template.csv` / `invoices-sample.csv` — who owes you and when
- `freelancer_finance_tracker.py` — live dashboard CLI
- `start-here.md` / `faq.md` / `finance-tracker-guide.md`
