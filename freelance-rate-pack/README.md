# Freelance Rate & Proposal Pack

Shameless clone of [Matt Kallaway's Freelance Rate & Proposal Pack ($14 on Gumroad)](https://mattkallaway.gumroad.com/l/bomum).

## What's inside

| File | Purpose |
|------|---------|
| `rate-calculator.html` | Browser rate floor calculator (offline, no signup) |
| `proposal-template-1-project.html` | Fixed-scope project proposal |
| `proposal-template-2-retainer.html` | Monthly retainer proposal |
| `proposal-template-3-audit.html` | Technical audit proposal |
| `start-here.md` | Setup in 2 minutes |

Buyer-channel shape cloned from [Matt Kallaway's dev.to rate article](https://dev.to/mattkallaway/how-i-calculate-my-minimum-hourly-rate-before-every-new-client-2k98).

Open any HTML file in your browser. Swap bracketed fields. Print to PDF for proposals.
